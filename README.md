# \# Travel Fund Dashboard

# 

# A shared savings tracker for two people contributing toward a joint travel goal.

# 

# \## Overview

# 

# A lightweight web application that allows two people to track savings held in separate accounts. Users can manually record contributions without connecting their bank accounts.

# 

# \## Features

# 

# \- Track contributions from two separate users

# \- Add and subtract deposits

# \- Display the combined savings balance

# \- Synchronize contributions across devices using Supabase

# \- Convert between currencies using exchange-rate data

# 

# \## Technologies

# 

# \- HTML and CSS — User interface

# \- JavaScript — Application logic

# \- Supabase — Shared database and real-time synchronization

# \- Frankfurter API — Currency conversion

# \- Netlify — Web hosting

# 

# \## Background

# 

# Built to solve a personal problem: allowing two people living in different countries to track their contributions toward a shared travel goal without connecting their bank accounts.

# 

# \## Setup

# 

# 1\. Clone or download the repository.

# 2\. Create and configure a Supabase project.

# 3\. Review the provided database schema and set appropriate Row Level Security policies.

# 4\. Copy `config.example.js` to `config.js` and enter your project configuration.

# 5\. Open the application through a local web server.

# 

# \## Note

# 

# This application tracks manually entered savings contributions; it does not connect to real bank accounts.
